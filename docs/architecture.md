# 🏛️ 四層式系統架構設計 (Four-Layered Architecture)

AIPALS (MAAP) 平台採用高內聚、低耦合的四層式架構設計，確保系統在處理高頻率的 AI 請求、演算法運算與資料庫讀寫時，具備優異的可維護性與擴充性。

---

## 📐 系統層級與職責分工
+-------------------------------------------------------+
| 1. Presentation Layer (展示層 / Web UI)               |
|    - ASP.NET MVC Views / Web IDE                      |
+-------------------------------------------------------+
│
▼
+-------------------------------------------------------+
| 2. Application Layer (應用層 / 核心後端)               |
|    - C# Controller & Service / Adaptive Algorithm     |
+-------------------------------------------------------+
│
▼
+-------------------------------------------------------+
| 3. AI Service Layer (AI 服務層 / Multi-Agent)         |
|    - HttpClient / OpenAI Assistant API v2 / Agents    |
+-------------------------------------------------------+
│
▼
+-------------------------------------------------------+
| 4. Data Layer (資料層 / 數據持久化)                    |
|    - MS SQL Server / Entity Framework Core (Database-First) |
+-------------------------------------------------------+
